# Tarea: Diseño de un prompt profesional

## Funcionalidad elegida

Registro de clientes en Java.

## Version 1
Crea un programa en Java para registrar clientes.

## Version 2
Actua como desarrollador Java. Crea un programa para registrar clientes con los datos ID, nombre, apellido, correo y telefono. Organiza el codigo usando una clase Cliente y una clase Main.

## Version 3
Actua como desarrollador Java. Crea un programa para registrar clientes en una tienda. Cada cliente debe tener ID, nombre, apellido, correo y telefono. Usa una clase Cliente y una clase Main. No uses librerias externas. Valida que el correo contenga @ y muestra primero una breve explicacion y despues el codigo Java.
## Prompt final
Actua como desarrollador Java. Crea un programa para registrar clientes en una tienda. Cada cliente debe tener ID, nombre, apellido, correo y telefono. Usa una clase Cliente y una clase Main. No uses librerias externas y valida que el correo contenga @. Usa este estilo para los metodos: getNombre() y getCorreo(). Muestra primero una breve explicacion y despues el codigo Java.
## Componentes del prompt final
| Componente | Parte del prompt |
|------------|------------------|
| Rol | Actua como desarrollador Java. |
| Instruccion | Crea un programa para registrar clientes. |
| Contexto | El programa es para registrar clientes en una tienda. |
| Ejemplo | Usa este estilo para los metodos: getNombre() y getCorreo(). |
| Formato | Muestra primero una breve explicacion y despues el codigo Java. |
## Evaluacion del resultado
| Criterio | Cumple |
|----------|--------|
| ¿El programa esta hecho en Java? | Si |
| ¿Usa las clases Cliente y Main? | Si |
| ¿Registra ID, nombre, apellido, correo y telefono? | Si |
| ¿Valida que el correo contenga @? | Si |
| ¿Usa metodos como getNombre() y getCorreo()? | Si |
| ¿Muestra primero una explicacion y despues el codigo? | Si |
| ¿Evita el uso de librerias externas? | Si |
## Errores frecuentes y como los evite
1. **Ser demasiado general:** Al inicio mi prompt era muy corto y no explicaba bien lo que queria. Lo evite agregando los datos del cliente, las clases que debia usar y la validacion del correo.
2. **No indicar el formato:** En el primer prompt no indique como queria la respuesta. Lo mejore pidiendo que primero muestre una breve explicacion y despues el codigo Java.
